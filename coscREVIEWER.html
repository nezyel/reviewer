PROPOSITIONAL LOGIC

statemets true and false can be assigned
purpose is to analyze these statements either individually or in a composite manner

Examples of Propositions

  1. "Man is Mortal", it returns truth value "TRUE"
  2. "12+9 = 10", it returns truth value "FALSE"
  3. "Mr. Lyndon B. Torres is a College Instructor", it returns truth value "TRUE"

Examples of Non-Proposition

  1. "A is less than 2". It is because unless we give a specific value of A, we cannot say whether the statement is true or false.
  2. "2+x > 8". It is because unless we give a specif ic value of x, we cannot say whether the statement is true or false.

Logical Operators

statements or propositional variables can be combined by means of logical connectives (operators) to form a single statement called compound statements

Basic Connectives (Operators)

  1. NEGATION / NOT ~ opposite of original statement.
    • if A is a statement the negation is Not A
    • Paris is in France, Paris is not in France
  2. CONJUNCTION / AND ∧ both statements true = TRUE
    • T and T = True
    • F and T = False
    • F and F = False
  3. DISJUNCTION / OR ∨ both statements false = FALSE
    • F or F = False
    • T or F = True
    • T or T = True
  4. IMPLICATION / IF-THEN ⇒ 1st true and 2nd false = FALSE
    • T if-then F = False
    • T if-then T = True
    • F if-then T = True
  5. IF AND ONLY IF ↔ same statement = TRUE
    • T if and only if T = True
    • F if and only if F = True
    • T if and only if F = False

Derived Connectives

  1. NAND ↑ means NOT AND
    • opposite of CONJUNCTION / AND
    • both statement true = FALSE
    • T not and T = False
    • T not and F = True
    • F not and F = True
  2. NOR ↓ means NOT OR
    • opposite of DISJUNCTION / OR
    • both statement false = TRUE
    • F not or F = True
    • F not or T = False
    • T not or T = False
  3. XOR (EXLUSIVE OR) ⊕
    • opposite of IF AND ONLY IF THEN
    • same statement = FALSE
    • not same statement = TRUE
    • T ⊕ T = False
    • T ⊕ F = True
    • F ⊕ F = False
